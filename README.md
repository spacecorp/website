# Space Corp Website

A small static Next.js website built with styled-components for Space Corp.

## Local development

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the site locally:
   ```bash
   npm run dev
   ```

## Build and export

```bash
npm run build:static
```

Static files are exported to the `out` folder.

## Deploy

This project includes a deploy script for GitHub Pages:

```bash
npm run deploy
```

> If you want to deploy to `https://spacecorp.github.io`, make sure this repository is the `spacecorp.github.io` repo or set the correct GitHub Pages source in the repository settings.
